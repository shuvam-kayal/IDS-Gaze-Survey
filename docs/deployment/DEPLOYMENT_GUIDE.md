# Deployment guide

Docker Compose is the first supported target. Before non-local deployment: use managed secrets; replace demo database credentials; enable TLS, backups and restore drills; add authentication, authorization, tenant isolation, audit and rate limiting; configure strict CORS/origin allowlists; define retention/deletion and incident response; pin/scan dependencies and images; add production readiness, migrations and rollback; load-test ingestion and processing separately; complete ethics, privacy and security review before real recruitment.
