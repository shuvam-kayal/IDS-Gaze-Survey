# ML evaluation plan

P4 owns interpretation and model evaluation; P3 owns measurement quality and feature definitions. Start with descriptive statistics and transparent baselines. Define outcomes, hypotheses, exclusions and metrics where possible. Split by participant/session rather than random rows to reduce leakage; group by study/site when appropriate. Report sample sizes, missingness, uncertainty, effect sizes, calibration and class imbalance. Compare gaze and non-gaze modes only on defined cohorts and discuss permission self-selection. Distinguish association from causation and attention proxies from internal cognitive states. Version datasets, feature sets, code, parameters and seeds. If sample size or quality is inadequate, return `insufficient_data` with limitations rather than overconfident conclusions.
